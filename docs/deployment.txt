SECTION 1 — OVERVIEW
================================================================================

  Both frontend and backend are hosted on Vercel.
  The database is hosted on Neon (Serverless PostgreSQL).
  Images are stored on Cloudinary.
  Payments are handled by Razorpay.

  Architecture:

    User Browser
         ↓
    Vercel (Frontend - Next.js)         → https://cloth-store-pied-five.vercel.app
         ↓  fetch() API calls
    Vercel (Backend - Flask Serverless) → https://cloth-store-backend-chi.vercel.app
         ↓  SQL queries
    Neon PostgreSQL (Database)

================================================================================
SECTION 2 — BACKEND (Flask on Vercel)
================================================================================

  Provider      : Vercel
  Live URL      : https://cloth-store-backend-chi.vercel.app
  GitHub Branch : backend
  Root Dir      : /backend
  Runtime       : Python (via @vercel/python)
  Entry Point   : app.py
  Config        : vercel.json

  How Vercel runs Flask:
    - vercel.json tells Vercel to use @vercel/python to run app.py
    - Every API route becomes a serverless function
    - No gunicorn needed (Vercel handles the WSGI server internally)

  Required Environment Variables in Vercel Dashboard:
  ─────────────────────────────────────────────────────────────
    DATABASE_URL           = Neon PostgreSQL connection string
    SECRET_KEY             = Random secure string for JWT signing
    FRONTEND_URL           = https://cloth-store-pied-five.vercel.app
    CLOUDINARY_CLOUD_NAME  = Your Cloudinary cloud name
    CLOUDINARY_API_KEY     = Your Cloudinary API key
    CLOUDINARY_API_SECRET  = Your Cloudinary API secret
    RAZORPAY_KEY_ID        = Your Razorpay key ID
    RAZORPAY_KEY_SECRET    = Your Razorpay key secret

SECTION 3 — FRONTEND (Next.js on Vercel)
================================================================================

  Provider      : Vercel
  Live URL      : https://cloth-store-pied-five.vercel.app
  GitHub Branch : frontend
  Root Dir      : /frontend

  ─────────────────────────────────────────────────────────────

  NOTE: NEXT_PUBLIC_ prefix exposes the variable to the browser.
        Never put secret keys with this prefix.

================================================================================
SECTION 4 — DATABASE (Neon PostgreSQL)
================================================================================

  Provider      : Neon (Serverless Postgres)
  Tables        : user, product, order, order_item
  ORM           : Flask-SQLAlchemy
  Driver        : psycopg2-binary

  The DATABASE_URL is set as an environment variable on Vercel backend.
  It connects to Neon over SSL (sslmode=require).

================================================================================
SECTION 5 — IMAGE STORAGE (Cloudinary)
================================================================================

  Provider      : Cloudinary
  Why needed    : Vercel serverless has NO persistent file system.
                  Images cannot be stored on Vercel directly.
  How it works  :
    1. Admin uploads image via Admin Dashboard (frontend)
    2. Frontend sends image to Flask backend as multipart form
    3. Flask uploads to Cloudinary via Python SDK
    4. Cloudinary returns a secure URL
    5. Flask saves that URL in the product's image_url column in Neon DB
    6. Frontend displays the Cloudinary URL in product cards

================================================================================
SECTION 6 — PAYMENTS (Razorpay)
================================================================================

  Provider      : Razorpay
  Mode          : Test (rzp_test_*)
  How it works  :
    1. User clicks "Pay Now" on cart page
    2. Frontend calls POST /api/orders
    3. Flask creates order in DB + creates Razorpay order
    4. Razorpay order ID returned to frontend
    5. Frontend opens Razorpay payment popup
    6. User pays → Razorpay calls frontend with payment ID + signature
    7. Frontend calls POST /api/orders/verify
    8. Flask verifies Razorpay signature
    9. Order status updated to "Paid" in DB

SECTION 7 — HOW TO DEPLOY (Step by Step)
================================================================================

  BACKEND:
  ─────────────────────────────────────────────────────────────
    1. Push changes to 'backend' branch on GitHub
    2. Vercel auto-deploys from backend branch
    3. Make sure all env vars are set in Vercel dashboard

  FRONTEND:
  ─────────────────────────────────────────────────────────────
    1. Push changes to 'frontend' branch on GitHub
    2. Vercel auto-deploys from frontend branch
    3. Make sure NEXT_PUBLIC_API_URL is set in Vercel dashboard
