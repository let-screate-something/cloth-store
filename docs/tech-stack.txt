Project       : Cloth Store (E-commerce)

--------------------------------------------------------------------------------
ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------

The application is split into two independent services:

  FRONTEND  →  Handles UI, 3D animations, routing, and state management
  BACKEND   →  Handles business logic, data, and serves a RESTful JSON API

Both services communicate over HTTP. The frontend NEVER directly touches the
database — all data goes through the Flask API.

================================================================================
SECTION 1 — FRONTEND  (/frontend)
================================================================================

  Framework         : Next.js 15
  Language          : TypeScript
  UI Library        : React
  Styling           : Tailwind CSS
  State Management  : Zustand
  3D Interactions   : Spline  (@splinetool/react-spline)
  Port              : http://localhost:3000

  Details:
  ─────────────────────────────────────────────────────────────
  Next.js 15
    - Uses the App Router (/app directory) for file-based routing
    - Supports Server Side Rendering (SSR) and Static Site
      Generation (SSG) for SEO-friendly pages

  TypeScript
    - Strict typing for all components and API response shapes
    - Custom interfaces like Product and CartItem live in
      lib/store/cartStore.ts for reusability

  Tailwind CSS
    - Utility-first approach for styling directly in JSX
    - Dark theme used throughout (bg-neutral-950, text-white)

  Zustand
    - Lightweight global state store for the shopping cart
    - No Redux boilerplate; simple create() API
    - Cart state persists across page navigations

  Spline  (3D)
    - Visual 3D scene editor — no raw Three.js code needed
    - Embedded via <Spline scene="..." /> in the hero section
    - Users can interact with the 3D scene in real time

================================================================================
SECTION 2 — BACKEND  (/backend)
================================================================================

  Framework         : Flask 3.0.3
  Language          : Python 3
  API Style         : RESTful  (returns JSON)
  CORS Handling     : Flask-CORS 4.0.1
  Env Management    : python-dotenv 1.0.1
  Port              : http://localhost:5000

  Details:
  ─────────────────────────────────────────────────────────────
  Flask
    - Micro-framework, minimal setup, easy to extend
    - Chosen because the developer is most comfortable in Python
    - Each route is a simple Python function decorated with
      @app.route(...)

  Flask-CORS
    - Configured to allow requests from http://localhost:3000
    - Prevents browser "blocked by CORS policy" errors during
      development

  python-dotenv
    - Loads .env file into environment variables at startup
    - Used for SECRET_KEY, DATABASE_URL, etc.

  API Endpoints  (current):
  ─────────────────────────────────────────────────────────────
    GET  /api/health               → Returns {"status":"healthy"}
    GET  /api/products             → Returns list of all products
    GET  /api/products/<id>        → Returns a single product

================================================================================
SECTION 3 — COMMUNICATION LAYER
================================================================================

  Protocol     : HTTP / HTTPS
  Data Format  : JSON
  Client Tool  : Native browser fetch() API  (in Next.js pages)

  Flow:
    Browser → Next.js Page (fetch) → Flask API → JSON Response → Rendered UI

================================================================================
SECTION 4 — PLANNED / UPCOMING TECHNOLOGIES
================================================================================

  Database     : SQLite  (development)  →  PostgreSQL  (production)
  ORM          : SQLAlchemy  (maps Python classes to database tables)
  Auth         : NextAuth.js (frontend) + JWT tokens validated by Flask
  Payments     : Stripe API  (handled entirely in Python backend)
  3D Models    : Custom Spline scenes or .glb files loaded via R3F
