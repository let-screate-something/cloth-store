SECTION 1 — HOW THE FRONTEND WORKS (Big Picture)
================================================================================

  User opens browser
       ↓
  Vercel serves the Next.js app  (HTML + JS)
       ↓
  Next.js page loads in the browser
       ↓
  React components send fetch() requests to Flask API
       ↓
  Flask (on Vercel Backend) returns JSON data
       ↓
  React renders the data on screen (products, cart, orders, etc.)

SECTION 3 — KEY FILES EXPLAINED
================================================================================

  app/page.tsx  (Homepage)
  ─────────────────────────────────────────────────────────────
  - Uses 'use client' for interactive React state
  - Renders a 3D Spline scene in the hero section
  - Fetches all products from /api/products
  - Renders product cards with "Add to Cart" button

  app/shop/page.tsx
  ─────────────────────────────────────────────────────────────
  - Full product listing with category filters
  - Fetches all products from the backend
  - Add to Cart functionality

  app/product/[id]/page.tsx
  ─────────────────────────────────────────────────────────────
  - Dynamic route — [id] = product ID from DB
  - Fetches single product from /api/products/<id>
  - Detailed product view with Add to Cart button

  app/cart/page.tsx
  ─────────────────────────────────────────────────────────────
  - Reads cart state from Zustand cartStore
  - Displays items, quantities, subtotal, total
  - "Checkout" triggers Razorpay payment popup
  - On successful payment, calls /api/orders/verify

  app/login/page.tsx
  ─────────────────────────────────────────────────────────────
  - POST /api/auth/login with email + password
  - Saves JWT token to localStorage
  - Redirects to homepage on success

  app/register/page.tsx
  ─────────────────────────────────────────────────────────────
  - POST /api/auth/register with name + email + password
  - Redirects to login page on success

  app/profile/page.tsx
  ─────────────────────────────────────────────────────────────
  - Protected route — redirects to /login if not logged in
  - GET /api/auth/me to show user info
  - GET /api/orders/me to show order history

  app/admin/page.tsx
  ─────────────────────────────────────────────────────────────
  - Protected admin-only route
  - Upload new products (name, price, category, description, image)
  - View all orders from all users
  - GET /api/admin/orders

  components/Navbar.tsx
  ─────────────────────────────────────────────────────────────
  - Shows Login / Sign Up if user is not logged in
  - Shows Profile / Admin / Logout if user is logged in
  - Shows cart item count badge (from Zustand cartStore)
  - Admin link only visible to admin users

  lib/store/cartStore.ts
  ─────────────────────────────────────────────────────────────
  - Global state manager built with Zustand
  - Functions:
      addItem(product)     → adds item or increments quantity
      removeItem(id)       → removes item completely from cart
      updateQuantity(id)   → updates quantity of an item
      clearCart()          → empties the entire cart
  - State shared across ALL pages without prop drilling

SECTION 4 — DATA FLOW (Step by Step)
================================================================================

  STEP 1 — Page Loads
    Browser requests https://cloth-store-pied-five.vercel.app
    Vercel serves the Next.js HTML/JS bundle

  STEP 2 — React Mounts
    React initializes the page component
    useEffect() hook triggers on first render

  STEP 3 — API Call to Flask
    fetch(`${NEXT_PUBLIC_API_URL}/api/products`)
    → GET https://cloth-store-backend-chi.vercel.app/api/products

  STEP 4 — Flask Responds
    Flask checks CORS (allows cloth-store-pied-five.vercel.app)
    Returns JSON: [ {id, name, price, category, description, image_url}, ... ]

  STEP 5 — React Updates State
    setProducts(data) is called
    React re-renders the product grid with real data

  STEP 6 — User Adds to Cart
    User clicks "Add to Cart" on a product card
    addItem(product) is called in cartStore.ts
    Zustand updates global cart state instantly
    Cart count badge updates in Navbar — no page reload needed

  STEP 7 — User Checkout
    User goes to /cart
    Clicks Checkout → POST /api/orders → Razorpay popup opens
    User pays → POST /api/orders/verify → order marked Paid in DB
    Cart is cleared

================================================================================
SECTION 5 — AUTHENTICATION FLOW
================================================================================

  Register:
    User fills form → POST /api/auth/register → account created

  Login:
    User fills form → POST /api/auth/login
    Backend returns { token, user }
    Frontend saves token to localStorage
    user object stored in app state (for Navbar etc.)

  Staying Logged In:
    On every page load, frontend reads token from localStorage
    Sends GET /api/auth/me to verify token is still valid
    If valid → user stays logged in
    If invalid/expired → redirected to /login

  Logout:
    Token removed from localStorage
    User state cleared
    Redirected to homepage
