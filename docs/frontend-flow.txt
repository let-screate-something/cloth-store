SECTION 1 — HOW THE FRONTEND WORKS (Big Picture)
================================================================================

  User opens browser
       ↓
  Vercel serves the Next.js app  (HTML + JS)
       ↓
  Next.js page loads in the browser
       ↓
  React components send fetch() requests to Flask API
       ↓
  Flask (on Render) returns JSON data
       ↓
  React renders the data on screen (products, cart, etc.)

SECTION 3 — KEY FILES EXPLAINED
================================================================================

  app/page.tsx
  ─────────────────────────────────────────────────────────────
  - The homepage of the store
  - Uses 'use client' because it has interactive React state
  - On load: fetches /api/products from the Flask backend
  - Renders a 3D Spline scene in the hero section
  - Renders product cards below the hero
  - Each card has an "Add to Cart" button

  lib/store/cartStore.ts
  ─────────────────────────────────────────────────────────────
  - Global state manager built with Zustand
  - Stores all items currently in the shopping cart
  - Functions:
      addItem(product)     → adds item or increments quantity
      removeItem(id)       → removes item completely from cart
      clearCart()          → empties the entire cart
  - State is shared across ALL pages without prop drilling

  src/app/layout.tsx
  ─────────────────────────────────────────────────────────────
  - Root layout that wraps every page
  - Sets the HTML <head>, fonts, and metadata
  - Any Navbar or Footer component would go here

SECTION 4 — DATA FLOW (Step by Step)
================================================================================

  STEP 1 — Page Loads
    Browser requests https://cloth-store-pied-five.vercel.app
    Vercel serves the Next.js HTML/JS bundle

  STEP 2 — React Mounts
    React initializes the page component
    useEffect() hook triggers on first render

  STEP 3 — API Call to Flask
    fetch(`${NEXT_PUBLIC_API_URL}/api/products`)
    → GET https://cloth-store-myff.onrender.com/api/products

  STEP 4 — Flask Responds
    Flask checks CORS (allows cloth-store-pied-five.vercel.app)
    Returns JSON: [ {id, name, price, category, description}, ... ]

  STEP 5 — React Updates State
    setProducts(data) is called
    React re-renders the product grid with real data

  STEP 6 — User Adds to Cart
    User clicks "Add to Cart" on a product card
    addItem(product) is called in cartStore.ts
    Zustand updates global cart state instantly
    Cart count updates in the UI — no page reload needed

SECTION 5 — ENVIRONMENT VARIABLES
================================================================================

  Local Development  (.env.local)
  ─────────────────────────────────────────────────────────────
    NEXT_PUBLIC_API_URL = http://localhost:5000

  Production  (set in Vercel dashboard)
  ─────────────────────────────────────────────────────────────
    NEXT_PUBLIC_API_URL = https://cloth-store-myff.onrender.com

  NOTE: Variables prefixed with NEXT_PUBLIC_ are exposed to the
        browser. Never put secret keys with this prefix.

SECTION 6 — HOW TO RUN LOCALLY
================================================================================

  Prerequisites:
    - Node.js installed
    - Flask backend running on localhost:5000

  Commands  (run from /frontend folder):
  ─────────────────────────────────────────────────────────────
    npm install         ← install all dependencies (first time only)
    npm run dev         ← start dev server on http://localhost:3000

SECTION 7 — HOW TO DEPLOY (Vercel)
================================================================================

  Automatic Deploy:
    Every push to the 'frontend' branch on GitHub
    automatically triggers a new Vercel deployment.

  Manual Deploy:
    Go to vercel.com → cloth-store project → Deployments
    Click "Redeploy"

  Build Command  : next build   (Vercel runs this automatically)
  Output Dir     : .next        (Vercel knows this automatically)
